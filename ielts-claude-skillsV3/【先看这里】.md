# IELTS Skills V3 for Codex · 5 分钟安装

这版已经适配 Codex。你不用装 Claude Code，也不用输入 `/ielts` 斜杠命令。直接跟 Codex 说“我要备考雅思”“帮我批改这篇雅思作文”“打开雅思 dashboard”即可。

## 1. 安装 skills

在 Windows 的 CMD 里进入这个文件夹，运行：

```cmd
install-codex.bat
```

它会把 8 个 IELTS skill 和 dashboard 复制到：

```text
%USERPROFILE%\.codex\skills
```

Mac / Linux / Git Bash 运行：

```bash
bash install-codex.sh
```

## 2. 在 Codex 里使用

直接说自然语言：

- 我要备考雅思
- 分析我的雅思成绩
- 帮我批改这篇雅思作文
- 分析这篇阅读错题
- 分析这套听力错题
- 帮我准备口语 Part 2 素材
- 带我练雅思词汇
- 打开雅思 dashboard

## 3. 启动 dashboard

第一次启动需要装依赖：

```cmd
cd /d "%USERPROFILE%\.codex\skills\ielts-dashboard\dashboard"
npm.cmd install
npm.cmd start
```

打开：

```text
http://localhost:5173
```

如果 PowerShell 里直接打 `npm` 报错，请用 `npm.cmd`。

## 4. 数据在哪里

你的备考数据都在：

```text
%USERPROFILE%\.ielts
```

程序在：

```text
%USERPROFILE%\.codex\skills
```

升级程序时不要删 `.ielts`；那是你的学习档案。
