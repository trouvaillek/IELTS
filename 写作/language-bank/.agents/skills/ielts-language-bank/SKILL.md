# 雅思积累与复习

## 找到资料库

优先使用当前项目中同时含 `bank.py`、`entries/` 的目录；项目中的本文件位于资料库的 `.agents/skills/ielts-language-bank/`。
若从全局安装副本启动，查找当前工作区内的资料库；未找到时询问位置，不创建另一份主库。
所有路径相对于资料库根目录，不能写死某台电脑的盘符。此资料库不与旧 `ielts-vocab` 的 `~/.ielts/` 双写。
操作格式和字段见 [references/schema.md](references/schema.md)。Python 3.10+，仅使用标准库。

## 同步与权限范围

用户已选用 GitHub 管理此库。已配置并确认目标的仓库内，录入和完成复习后正常提交、推送属于这套工作流；不据此发布其他文件、改变可见性或操作其他仓库。
开始时检查 `git status --short`、分支、上游与远程地址。工作区干净且有上游时运行 `git pull --ff-only`。未配置上游时说明尚未配置，不假称已同步。
网络失败可以继续在本机学习，并明确说明“本机已保存，尚未同步”。存在未提交修改时先判断是否属于本次工作，保留他人的修改，不自动 stash。
结束时用 `python bank.py validate` 验证，`python bank.py refresh` 更新浏览页和统计，只 stage 本次学习库相关文件，正常 commit/push。不使用 `git add .`、强推或丢弃更改。
push 被拒绝后最多进行一次 fetch 和差异诊断：仅当更改可明确无损合并时合并；同一用户造句的不同修改或无法判断的冲突保留双方并解释。不要用复习次数相加解决冲突，应从唯一事件 ID 重新计算。重试仍失败则保留本地提交并报告。
技能本身不会在后台运行；同步发生在 Codex 执行这套流程时。上传前查看 staged diff，不能夹带本机配置、密钥或无关文件。

## 录入

1. 读取用户正文及附件，把昵称、时间戳作为来源元数据，不当成词条。仅有聊天日期时记为“笔记记录日期”，不冒充最初学会日期。未知日期为 null；收录日期按本机 Asia/Shanghai 当日。
2. 保留用户原文和给出的释义；补充标准表达、中文释义、必要搭配说明。上下文不明写“来源未记录”，不能编题号、书名或声称句子由用户原创。
3. 明显拼写错误可纠正，保留原写法；不确定的原意设置 `quality: needs_context` 并说明候选解释，默认不出题。已有释义但尚未逐项核实标 `unverified`，默认不当标准答案。核实后才改成 `ready`。检查原文可疑搭配，不能机械照抄成标准表达。
4. 按表达去重，合并同义项的来源记录但不丢弃语义区别。单复数可分别保留并关联；不同含义在同一词条中说明。复习历史不能因再次导入重置。
5. 标签表示建议训练用途（reading/writing/speaking/general），不表示已经知道出处。生成例句明确标 AI 示例。`我的造句` 留空，除非用户明确说是自己写的；已提供的造句始终保留原句，修改版另存。
6. 准备结构化批次 JSON，用 `python bank.py import <batch.json>` 录入。已存在词条需要纠错时先读全文，修改对应字段/说明，不覆盖已有用户造句和来源。运行 refresh/validate，报告新增、合并、待确认数量及重要纠正。

## 抽查与反馈

默认使用 `python bank.py due --limit 10` 获取当天到期且 quality=ready 的词条。优先到期最久、最近答错者；日期相同随机抽取，不固定只考前几个。用户指定范围/最近收录/随机模式时遵循范围；到期不足可补未到期词，说明补充。全部未核实时先核实小批，不以错误释义出题。
一次只问一道，默认混合中译英、搭配填空和自主造句；阅读可英译中/同义替换，写作强调正式搭配，口语强调自然表达。先给题目，等用户答完再给答案，不先把答案表展示出来。
判定为 correct（独立正确）、partial（提示后答出或有关键小错）、wrong（错误/不会）。合理同义答案也可正确；不强制匹配唯一字符串。用户仅看题、跳过、停止或尚未回答不新增复习事件；明确回答“不知道”并接受反馈可以记 wrong。
用短中文解释关键点。造句反馈保留用户原句和建议修改句，不拿 AI 示例冒充用户回答。
完成回答及反馈后准备事件 JSON，运行 `python bank.py record <event.json>`，再同步。每次事件用新 UUID；因重试保存同一次回答时复用原 UUID。复习次数来源于已完成的唯一事件；同一事件重放不能重复计数。
正确间隔依次为 1、3、7、14、30、60 天（从本次实际复习日计算），partial/wrong 重置连续正确并安排次日复习。连续正确三次标 familiar，六次标 mastered，但仍保留长期抽查。导入初始 review_count=0、last_review=null、next_review=收录当日；不要推断以前复习过。

## 导出与交付

`INDEX.md` 是可重建浏览表，`REVIEW-QUEUE.md` 是待核实列表。entries/ 和 reviews/ 是主记录，索引不作手工改数入口。
用户要求表格时可 `python bank.py export` 生成 exports/language-bank.csv（Excel 可打开）；若明确要求 .xlsx，再生成真正的工作簿，不改扩展名伪装。Excel 是导出视图，反馈/编辑回写必须基于词条 ID。
结束时说明本机保存与远程同步是否分别成功。没有安装到另一台电脑时，不声称那台也已安装；跨端步骤见资料库 README。
