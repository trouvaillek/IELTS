## 每日抽查规则

1. 每天 5 条，一次一道，不提前展示答案。
2. 优先级：上次 wrong → partial → 未测试条目 → 已正确但到期复习条目。
3. 题型混合：中文论点→英文论点；给论点补英文原因；给论点/原因补一个可用于 Task 2 的例子；必要时要求用该素材造一句完整英文句。
4. 评分：correct=独立正确；partial=核心意思对但有关键词/语法/搭配错误；wrong=不会、明显偏离或需要直接给答案。
5. 每题反馈后把日期、条目 ID、题型、用户原回答、结果、关键纠正写入 QUIZ-LOG.md。
6. wrong/partial 次日优先重测；correct 之后隔 3 天、7 天、14 天逐步抽查。
7. 源表中的机构、研究和事实型例子按原文保留，未做外部事实核验；复习重点是论证结构与英语表达，正式写作前如需引用具体研究应另行核实。
